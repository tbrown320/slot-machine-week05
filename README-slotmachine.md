##Rules for a slot machine

Input (bet) - Needs to be positive
-Meaning greater than zero - Between a minimum and maximum bet amount - Needs to be equal to or smaller than your current "wallet" - Can bet more money than you have

Process - Reels need to randomize - Should give us one of our 5 options - Check if all reel value are the same - If yes - Multiply the input but the winning factor based on the selected option - Winning factor is the amount of money you get on top of your input back

        - If no
            - They get NOTHING, THEY LOSE, GOOD DAY SIR
            - They lose their input (bet) and get no winnings

    - Output
        - The amount returned from the "process"
